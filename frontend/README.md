# OpsTwin Live — frontend

React + Vite + TypeScript + Tailwind + Recharts. See the repository README for setup and `docs/api.md` for the API.

- `npm run dev` — dev server on :5173, proxies `/api` to `VITE_DEV_API_TARGET` (default http://localhost:8000)
- `npm run preview` — serves the production build on :4173 with the same proxy
- `npm test`, `npm run typecheck`, `npm run build`
